01 / START HERE

第一次使用

先建立一个客户，再走通一笔报价和订单。整个系统都围绕同一个客户保存业务历史。

客户→商机→报价→订单→供货→收款 / 出货
  1. 启动程序：在项目文件夹中双击 start.command，保持打开的终端窗口运行。
  2. 打开系统：在本机浏览器访问 http://127.0.0.1:5001/。
  3. 登录并修改密码：管理员账号为 admin，使用初始化时获得的密码；进入「设置 → 修改我的密码」。本指南不保存登录密码。
  4. 建立基础资料：如果有不同岗位，管理员先创建员工账号；再建立产品和供应商资料。单人使用时，管理员可以完成全部业务。
  5. 开始第一笔业务：新建客户并添加联系人，记录沟通需求，创建报价，客户确认后转为订单。
本地使用：当前程序只监听本机地址。同一台电脑可切换不同岗位账号；其他电脑不能通过这个地址访问你的系统。关闭网页不会删除数据，退出启动终端或关机后需要重新启动程序。
02 / PEOPLE

账号与角色权限

角色主要工作可访问的业务范围
管理员账号管理、客户分配、全部业务处理全部客户和订单，产品及供货成本，操作日志。
业务员客户跟进、商机、报价、订单与出货本人负责的客户及关联业务；不能登记收款或查看供货成本。
采购 / 生产产品、供应商、执行供货任务分配给自己的订单产品与任务；不显示订单销售价格、收款及订单附件。
财务到账登记、应收核对、收款更正订单、收款、相关附件及财务报表。
  1. 管理员打开「设置 → 新建账号」，填写登录账号、姓名、角色和初始密码。密码至少 10 位。
  2. 员工使用自己的账号登录。看不到某个菜单或操作时，先核对当前角色。
  3. 管理员可在设置中启用 / 停用账号、重置密码。管理员不能停用自己。
  4. 客户需要转交时，管理员在客户详情点击「编辑资料」，修改负责人并保存。原负责人的未完成关联待办会一并转交。
第一版的角色在创建账号时指定，界面未提供直接修改已有账号角色的入口。停用账号不会删除已有客户或订单。
03 / DAILY ROUTINE

每天从工作台开始

  1. 查看「我的待办」和逾期数量，优先处理已逾期事项。
  2. 完成行动后勾选待办；需要记录沟通结果时，进入对应客户的「记录跟进」。勾选待办本身不会自动生成沟通记录。
  3. 临时事项可以点击「添加待办」，填写事项与提醒日期，也可以关联客户。
  4. 查看销售漏斗，找出停留在询盘、报价或谈判阶段的机会。
  5. 查看按币种列出的订单金额、已收与待收金额，再进入订单核对供货、交期和出货进度。
工作台按当前账号权限显示数据。个人待办只显示当前登录人的任务；金额按币种分开统计。

04 / CUSTOMERS

客户、联系人与跟进

建立客户档案

  1. 打开「客户 → 新建客户」，填写公司名称、国家、来源、关注产品、客户类型和主要联系人。
  2. 管理员可以选择负责人；业务员创建的客户默认由本人负责。
  3. 保存后点击公司名称或「查看详情」，进入客户档案。
  4. 在联系人区域点击「添加」，补充采购、财务或其他联系人；已有联系人可单独编辑。

记录沟通并安排下一步

  1. 客户详情点击「记录跟进」，填写沟通内容并选择邮件、电话、WhatsApp、会议或其他渠道。
  2. 需要后续提醒时，填写「下一步行动」与「下次跟进日期」。保存后自动为客户负责人创建待办。
  3. 在「跟进记录」查看历史沟通；「报价记录」「订单记录」查看该客户的关联业务。
  4. 客户资料、询盘文件等可在客户详情的「附件」区域上传。
查找与归档：客户列表支持搜索公司、联系人、邮箱及客户类型筛选。公司名称不区分大小写查重。暂时不用的客户可归档，并在「已归档」页签查看和恢复；历史业务仍保留。

05 / SALES PIPELINE

用商机看板推进机会

同一客户可以有多条商机。建议为不同项目、采购计划或复购需求分别建立商机。

新询盘→需求确认→已报价→样品 / 谈判→待确认订单
  1. 打开「商机 → 新建商机」，选择客户，填写商机名称、预计金额、币种、下一步行动和预计成交日期。
  2. 点击商机卡片，修改阶段、下一步行动与预计成交日期，再保存。当前看板通过点击卡片更新阶段，不使用拖动操作。
  3. 要与后续成交关联时，在商机详情点击「创建关联报价」。这份报价转订单后，关联商机会自动标记为赢单。
  4. 未成交时选择「丢单」并填写原因；赢单与丢单记录会显示在「已结束商机」区域。
商机阶段变化不会自动生成跟进待办。如需提醒，请在客户跟进时填写下一步和日期，或在工作台添加待办。
展开界面示例 · 商机看板：按阶段查看项目和下一步行动
06 / PRODUCTS

产品与供应商资料

先建立可复用的产品资料

  1. 管理员或采购 / 生产人员打开「产品 → 新建产品」。
  2. 填写唯一 SKU、产品名称、规格、单位、默认供货方式、参考单位成本和成本币种。
  3. 点击产品卡片的「查看资料」，可编辑产品、增加供货来源或上传图片及资料。
  4. 第一张上传的产品图片会显示在产品卡片上；产品图片和规格资料也可作为附件下载。

维护外采与混合供货来源

  1. 进入「产品 → 供应商管理」，填写供应商名称、联系人和电话，点击「新增供应商」。
  2. 产品详情点击「供货来源」，选择自产或外采；外采时选择供应商，填写参考单位成本。
  3. 同一产品可建立多个供货来源。默认方式可以是混合供货，实际数量拆分在销售订单内安排。
产品参考成本属于内部信息，业务员不会看到。参考成本不会自动成为销售单价，也不会自动分配供货任务。产品归档不会改变历史报价和订单。

07 / QUOTATIONS

报价、版本与 PDF

创建一份报价

  1. 从「报价 → 新建报价」、客户详情的「新建报价」或商机详情的「创建关联报价」进入。
  2. 选择客户与币种，填写报价有效期、贸易术语及指定地点、付款条件、交期与备注。
  3. 选择已建产品，或手动填写产品名称、规格与单位；逐行填写数量及销售单价。
  4. 点击「添加产品」增加明细，检查各项后点击「创建报价」。数量为整数，单价最多两位小数。
状态 / 操作使用方法
草稿打开报价点击「编辑草稿」，可修改产品、数量、单价和商务条款；关联客户不可在草稿编辑中更改。
已发送 / 待确认在报价详情点击「更新状态」记录商务进度。系统不会替你发送邮件。
复制为新版本客户要求改价、改规格或条款时，复制为新版本并修改。旧版继续保留。
下载 PDF在报价详情点击「下载 PDF」，保存后自行通过邮件等方式发送给客户。
已转订单原报价保留作为成交依据，不能再直接修改。
每份报价只使用一个币种，支持 USD、EUR、CNY、GBP。更改产品主资料不会回写历史报价。贸易术语应同时写明指定地点，例如 FOB Ningbo。

08 / ORDERS

确认订单与安排交期

  1. 在已确认的报价详情点击「确认并转订单」，填写约定交期并创建订单。当前销售订单从报价生成。
  2. 打开「订单 → 查看订单」，核对客户、产品、数量、价格、商务条件与交期。
  3. 系统保存报价当时的明细和价格。相同报价重复执行转单不会创建第二笔相同订单。
  4. 点击「更新交期 / 状态」，按实际执行情况维护约定交期与业务状态。
  5. 合同、包装要求、物流资料及收款凭证可上传到订单附件。
进度由什么决定
业务状态负责人手动选择：待安排供货、供货执行中、待出货、已完成。新增供货任务会将状态改为供货执行中。
供货完成度按各任务数量及完成百分比计算；尚未分配的数量仍会影响整体完成度。
收款进度根据有效到账记录计算，作废记录不计入已收金额。
出货进度根据各产品所有出货批次的实际数量累计计算。
供货、收款、出货分别跟踪。业务状态不会代替实际进度，也不会因为收齐款项或全部出货就自动改成「已完成」。完成履约后由负责人确认状态。
展开界面示例 · 订单详情：产品、供货任务、收款与出货进度
09 / FULFILLMENT

自产、外采与混合供货

  1. 管理员或负责业务员进入订单详情，在具体产品行点击「分配供货」。
  2. 选择自产或外采，填写本次数量、责任人、计划完成日期。外采还需要选择供应商。
  3. 同一产品可多次分配任务，但已分配数量合计不能超过订单产品数量。
  4. 采购 / 生产人员登录后，在「订单」或工作台查看自己的任务，点击「更新」。
  5. 填写完成进度 0–100%、质检结果 / 备注及计划完成日期；管理员也可以更新任务。
操作示例

500 把椅子，300 把自产 + 200 把外采

在同一条订单产品下，先创建数量 300 的自产任务，再创建数量 200 的外采任务。两个任务分别维护责任人、交期和进度。

如果自产完成 100%，外采完成 50%，该产品对应的数量加权完成度为 80%；多产品订单按订单全部产品数量继续汇总。

产品资料中的供货来源与订单内的执行任务相互独立。建立产品或供应商后，需要在订单内实际分配任务；产品数量分配完后，不应再次追加超过剩余数量的任务。供货任务成本按订单币种填写。
10 / PAYMENTS

定金、尾款与收款更正

  1. 管理员或财务打开「收款与出货」，找到订单并点击「登记收款」；也可从订单详情进入。
  2. 核对订单币种与剩余应收，填写本次实际到账金额、到账日期和款项说明。
  3. 定金、阶段款、尾款分别登记。金额必须大于 0，且不超过订单剩余应收。
  4. 到账凭证可在订单详情的附件区上传，建议文件名包含到账日期和款项性质。
  5. 录错金额或订单时，在「收款与出货 → 收款记录」点击「更正 / 作废」，填写原因。作废后再重新登记正确记录。
金额示例

订单 USD 10,000，先收 30% 定金

第一次登记 USD 3,000，剩余应收为 USD 7,000；尾款实际到账后再登记 USD 7,000。

作废会保留原到账记录及原因，并重新计算余额。系统不自动读取银行流水，也不自动进行外币换算；登记的是人工核对后的实际款项。
11 / SHIPMENTS

按产品登记分批出货

  1. 管理员或负责业务员在「收款与出货」或订单详情点击「登记出货」。
  2. 填写提单 / 运单号、出货日期与目的地 / 港口。
  3. 在各产品行填写本批实际数量；本次不出的产品保持 0。
  4. 提交后，系统为本批出货保留记录，并累加各产品已出数量。数量不能超过剩余可出货数量。
  5. 下次出货继续新增批次；在订单详情的「出货批次」查看日期、物流号、目的地与数量。
例如订单 500 把椅子，本批出 200，把椅子的本次数量填 200；下一批再登记 300。第一版没有出货批次的界面编辑 / 作废入口，提交前请核对产品、数量和物流号。
12 / REPORTS

查看报表与理解口径

指标统计口径
订单金额、已收、待收当前账号可访问订单的累计金额，按币种分别展示；作废到账不计入已收。
各阶段商机数量当前可访问商机的实际阶段数量，包括赢单和丢单。
客户市场分布按客户档案中的国家 / 地区统计客户数量。
按月订单金额按订单创建月份及币种统计；月份以北京时间计算。
报表不是预测利润表。不同币种不直接相加，订单总额不等于已回款金额。财务角色不开放销售商机，因此其报表中的商机数量不代表公司全部商机。

建议的日常检查

每天开始

逾期跟进 → 今日待办 → 待收款 → 订单交期。

每次沟通后

记录反馈 → 更新商机 → 安排下一步和提醒日期。

每天结束

核对到账与出货 → 更新供货进度 → 执行备份。

13 / DATA & FILES

CSV 导入导出与附件

批量导入客户

  1. 在「客户」点击「导出 CSV」，用导出的文件作为表头模板；按模板整理新客户资料。
  2. 保存为 UTF-8 编码的 CSV 文件，再点击「导入」选择文件。
  3. 每次 1–2000 行，至少填写公司名称。公司名称不区分大小写查重；重复公司跳过。
  4. 任何一行格式不合法时，整批导入撤销；修正后重新导入。导入成功会显示新增与跳过数量。
  5. 导入客户归当前操作人负责，管理员可再分配负责人。
公司名称,国家,联系人,邮箱,客户类型,来源,关注产品
示例客户有限公司,德国,Anna,anna@example.com,潜在客户,展会,户外家具
客户类型使用「潜在客户」「正式客户」或「重点客户」。导出的是当前账号可访问的客户基础资料及首位联系人，不包含完整跟进、订单或附件；CSV 不能代替系统备份。

上传和下载附件

在客户、产品或订单详情中，使用附件区域选择文件；上传成功后点击文件名下载。

规则说明
文件格式PDF、PNG、JPG、JPEG、WebP、CSV、XLSX、DOCX、TXT。
文件大小单次请求不超过 10 MB，包含表单开销；建议文件略小于 10 MB。
产品图片支持 PNG、JPEG、WebP，最多 2500 万像素；第一张图片用作卡片预览。
访问权限按所属客户、产品或订单校验权限。采购 / 生产人员不能访问订单附件。
保存位置文件保存在本机 instance/uploads；第一版不提供物理删除附件的界面入口。
14 / LOCAL OPERATIONS

启动、备份与恢复

启动与停止

macOS 双击 start.command 启动；终端显示地址后打开浏览器。停止程序时，在启动终端按 Ctrl + C。重新启动不会清空数据。

执行完整备份

  1. 双击项目文件夹中的 backup.command。也可以在项目目录的终端执行下方备份命令。
  2. 等待看到「备份完成」及文件路径。结果位于 backups/crm-日期时间.zip。
  3. 备份包包含数据库、已登记附件和清单。建议每天结束工作后备份，并另存一份到其他磁盘。
.venv/bin/python run.py backup
备份可以在程序运行时执行。不要只复制运行中的 crm.sqlite3 代替完整备份；数据库运行时还可能存在 WAL 日志，附件也在单独目录。备份是手动执行的，系统没有自动定时备份。

从备份恢复

  1. 先停止本地 CRM 服务。确认选中的是要恢复的完整备份包。
  2. 在项目目录的终端运行恢复命令，将示例路径替换为实际备份文件。
  3. 按提示输入 RESTORE。程序先校验备份，再保留恢复前副本、恢复数据库及附件。
  4. 恢复成功后双击 start.command 重启，并重新登录。旧会话会失效。
.venv/bin/python run.py restore "backups/crm-日期时间.zip"
恢复会将当前数据回退到备份时点。恢复前副本位于 backups/before-restore-日期时间。正式恢复前，请确认文件日期，必要时先做一次当前备份。

忘记管理员密码

在项目目录执行以下命令，按提示设置至少 10 位的新密码。输入密码时终端不显示字符。

.venv/bin/python run.py reset-password admin

终端命令从哪里运行？

打开「终端」，先输入 cd （末尾有空格），将项目文件夹拖入终端并回车，之后执行上述命令。Windows 用户将 .venv/bin/python 替换为 .venv\Scripts\python。

15 / HELP

常见问题与使用边界

网页打不开怎么办？

确认 start.command 打开的终端还在运行，地址是 http://127.0.0.1:5001/。如果刚关机或关闭启动终端，请重新启动程序。不要同时启动两份服务占用同一个端口。

提示端口被占用怎么办？

先检查是否已有 CRM 终端在运行。如果确需换端口，在项目目录执行 .venv/bin/python run.py serve --port 5002，然后访问 http://127.0.0.1:5002/。

为什么看不到客户、菜单或某个按钮？

检查账号角色和客户负责人。业务员只看本人负责的客户；采购 / 生产只看分配给自己的订单产品和任务。管理员可查看或重新分配客户。

为什么还没有客户和订单？

正式数据库初始为空。先新建客户，再创建报价并转订单。说明中的界面截图使用独立测试数据，不会自动出现在正式系统。

为什么不能编辑已发送报价？

对外发送后的报价应使用“复制为新版本”进行调整。新版本是可编辑草稿，旧报价继续保留。已转订单报价不能直接修改。

为什么报价不能选到某个客户？

报价客户选项只包含未归档客户。先在客户列表的“已归档”中恢复该客户，再创建报价。

为什么无法再次分配供货？

检查该产品订单数量及已分配数量。同一订单产品的全部供货任务数量合计不能超过订单数量；不要将包装配件当作同一产品额外数量重复分配。

为什么无法收款或出货？

先检查角色权限，再核对剩余应收或剩余产品数量。收款不能超过剩余应收；本批出货数量不能超过各产品的剩余数量。

系统会自动发邮件或同步 WhatsApp 吗？

当前版本手动记录沟通。报价 PDF 需要自行发送，系统不自动收发邮件、不同步 WhatsApp，也不自动读取银行流水。

换浏览器或清理浏览器缓存会删除数据吗？

业务数据保存在本机数据库及附件目录，不在浏览器缓存中。清理缓存后可能需要重新登录；不要删除项目中的 instance 文件夹。

同事可以从另一台电脑打开这个地址吗？

不能。127.0.0.1 始终指访问者自己的电脑，当前版本按本机部署运行。如以后需要局域网共享，应另行配置服务访问和部署方式。

关闭页面前需要点击“保存全部”吗？

没有“保存全部”。每次表单提交成功后即保存。未点击保存 / 创建、或出现错误提示的内容尚未保存；处理错误后再次提交。

提示会话校验失败怎么办？

刷新页面后重新操作，必要时退出再登录。同一浏览器中切换了账号或会话过期时，旧标签页需要刷新。

哪些数据不能从界面直接更正或删除？

客户可归档与恢复；收款可作废并重录。当前没有出货批次编辑 / 作废、供货任务数量调整 / 删除、订单产品金额修改和附件物理删除的界面入口。出现这类录入问题时先保留记录并联系维护人员处理，不要直接修改 SQLite 文件。

当前版本适合本地外贸业务管理；不含完整库存、生产排程、自动汇率、邮件营销和在线协同访问。指南依据当前实际功能编写，后续程序升级后应同步更新。
